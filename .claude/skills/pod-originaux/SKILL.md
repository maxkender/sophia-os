Lis `pods/originaux/AGENT.md` en entier avant d'agir : rôle, commandes
(`npm run label | images | apercu | deposer | etat` dans `pods/originaux/`),
recette et règles. `pods/originaux/ANALYSE.md` contient l'analyse du label.
Tout ce que tu produis passe par la file de validation (Pilotage → Pods) : tu
proposes, l'humain valide.
