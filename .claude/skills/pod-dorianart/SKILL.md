les liste (la preuve), et `pods/dorianart/posts/da-001.json` est le pilote
complet. Tout passe par la file de validation (Pilotage → Pods) : tu
proposes, l'humain valide, ou la livraison est validée toute seule 5 h après
son dépôt.
