## 3. Thèse

Le slideshow faceless **trouve le hook**. Le visage et la démo app
**encaissent les installs**. C’est le dossier Gizmo (phase 1 faceless →
phase 2 visages) et le contre-exemple ScrollToStudy (slideshow seul =
vues, pas d’installs).

Pour Sophia, ça se traduit en trois couches, dans cet ordre :

```
1. HARVEST     slideshow      déjà à l’échelle     optimiser le mix
2. PROUVE      papier + démo  ready, pas allumé    allumer et mesurer
3. ENCAISSE    visages        0 persona propre     seulement si 3 hooks tiennent
```

On ne scale pas les visages IA tant qu’on n’a pas **trois** hooks vidéo
qui font mieux que la médiane slideshow (1,3 k) **et** qui montrent
l’app ou un CTA App Store avant la fin.

Le nom « Sophia » n’est **pas** dans les 3 premières secondes d’une
vidéo, sauf ads assumées. Le slideshow continue de placer l’app
en slide milieu / fin — c’est déjà le cas du moteur.

## 6. Formats vidéo — ce qu’on teste (pas ce qu’on scale)

Recette commune, 8–26 s, adaptée culture (pas study) :

```
0–3 s   mythe ou douleur, texte plein écran
3–8 s   preuve sans l’app (photo, papier, fait)
8–20 s  pivot : l’app / le quiz / « cherche Sophia »
fin     CTA mou, pas le logo dans la première frame
```

| Code | Format | Qui le porte | Statut |
| --- | --- | --- | --- |
| **F4** | Slideshow | 110 posters | Scale — c’est le réseau |
| **F3** | Papier myth-busting | CM `@sophia.app.*` | Ready, 0 post |
| **F1** | Screen-record de l’app | À créer (pas dans l’OS) | **Manquant.** C’est le format Retain qui convertit |
| **F5** | Visage IA talking-head | `clara.culture510` | Pilote seulement |
| **F6** | Ranking / split | Slideshow déjà (Wilgo-style) | Dans le pool, pas isolé |

Le trou stratégique n’est pas « plus de personas ».
C’est **F1** : une vraie démo de l’app (quiz culture, streak, carte)
posée sur un bureau, 12–20 s. Ça n’existe pas dans le moteur.
Tant que F1 n’existe pas, le papier (F3) est le meilleur proxy.
